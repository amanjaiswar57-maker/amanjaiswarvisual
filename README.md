# Aman Jaiswar - Visual Creats

Portfolio website for **Aman Jaiswar** — Filmmaker, Cinematographer & Video Editor.

## 🚀 Overview
- **Aesthetic**: Cinematic dark mode, golden typography accents, balanced 50/50 video grid layout.
- **Tech Stack**: HTML5, Vanilla CSS3, React 18, Babel standalone, and a streaming-optimized Node.js server.
- **Features**:
  - Showreel video player
  - 10 Featured projects with unified aspect ratios and custom video controls
  - Category filters: All Projects, Reels & Commercials, Films & Music
  - Ambient blurred background glows on portrait video players
  - Direct WhatsApp inquiry integration

## 💻 Running Locally
```bash
npm run dev
# or
node server.js
```
Open [http://localhost:3000](http://localhost:3000) in your browser.
